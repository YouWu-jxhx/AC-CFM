# 验证与局限

GitHub Actions 在 Python 3.11 中检查生成器一致性、源清单、历史交换、数据篡改检测及提交完整性。Windows 授权 MATLAB 的验证入口使用相同仓库源码和已安装的 MATPOWER 8.1，无需安装额外求解器。

```powershell
pwsh -File tests/validate.ps1 -OutputDir runs/verify-20261126 -IncludeCrash
```

本地验证先做 Python 静态和单元验证，再运行 MATLAB 固定回归、扩展工况、保护分支夹具与恢复测试。随后独立读取全部场景，再用新结果执行含恢复 OPF 的 Python 验证。启用 `-IncludeCrash` 后检查真实进程强制终止和双 MATLAB 锁争用。许可证与 MATPOWER 路径须由运行者的会话提供。

- 固定回归比较原版、关闭快照与开启快照的物理矩阵、失供、图与 PF 次数。
- 双母线合成工况用真实 NR/MIPS 独立触发 UFLS、OFGS、XL、ULGT、UVLS、OL、VC、SH、恢复成功和恢复尝试耗尽停岛。另有真实 MIPS 成功后，核验 NR 在显式零迭代预算与 1e-13 容限下返回失败的边界测试。默认迭代预算下的自发失败仍不在独立夹具覆盖范围内。受控求解返回验证 PMIN 放宽、去除并联设备、核验失败与观察器错误。
- `has_solver_failure` 描述数值过程，可能与成功得到终态并存。 `model_opf_trip` 表示模型按其规则停岛。暂态电压、频率动态及真实保护时序需另以动态模型和观测验证。
- 已测试本地 NTFS 上进程退出与续算。搁置暂存、文件损坏与写入路径错误用可重复故障注入验证。实际磁盘耗尽、断电、网络卷和卡住进程自动恢复超出当前证据。
- 当前固定样本的规模、成功率和存储开销见性能报告。并行和更大工况需单独验证。
