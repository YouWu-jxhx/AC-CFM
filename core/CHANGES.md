# AC-CFM 源码变更记录

## 观察接口 v1

上游版本固定为 `48eebaa19b96b00ee40d7a86f5c1132be74efd8b`。原件在 `vendor/AC-CFM/accfm.m`，Windows 原文件 SHA-256 为 `316e37e2fb8745e6a734ce65cfb8118eee88cac1a3bf09a5b540546321075a7e`。

- `build_observed.py` 在固定语句位置生成 `accfm_observed.m`，并为入口使用独立函数名。
- 增加初始事件、岛进入及分岛、无可用电源等前置停岛、PF 输入和返回、PF 被上游捕获的异常、保护判定前、每组动作、OPF 恢复前及返回状态的记录。恢复后的核验 PF 单独标记。
- 记录器只读，不调用求解器或随机数函数。新增的 PF 包装执行原有单次调用，继续使用传入的 MATPOWER 选项。日志收集在内存中完成，批处理在单场景结束后落盘。
- 外部母线停运、运行条件校验、结果账本和保存协议在 `+accfmlab/` 中实现。

从工程根目录执行 `python core/build_observed.py` 可再生成观察版。维护时把观察点改动写入生成器并重跑固定场景回归。需要改保护模型时，应另建研究分支，记录规则差异，并补充能独立触发该规则的测试。批次计划记录所有执行用 MATLAB 源码的 SHA-256，变更后的运行应使用新输出目录。
